# P2 – 30A Home Automation with ESP32

## 📌 Overview

A custom PCB design for a high-power home automation system using an ESP32 as the main controller. The board is designed to interface with high-current AC loads through a 30A switching stage.

## 🛠️ Tools & Technologies

- KiCad
- ESP32
- PCB Design
- Schematic Design
- PCB Layout
- High-Current Switching
- Home Automation

## ⚡ Key Features

- ESP32-based control
- 30A high-current load switching
- AC load interface
- Dedicated power and control sections
- Compact PCB layout
- Designed with practical routing and component placement considerations

## 📐 Design Process

1. Circuit schematic design
2. Component selection
3. Footprint assignment
4. PCB layout
5. Power and signal routing
6. Design Rule Check (DRC)
7. Final PCB design
